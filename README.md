# Kelompok 8

Mata kuliah **Manajemen Proyek Perangkat Lunak (MPPL)**.

## 📌 Project

### Sistem Pengelolaan Pesanan pada UMKM Warung Kopi

Proyek ini bertujuan untuk mengembangkan sistem yang membantu kasir dalam
mencatat dan mengelola pesanan pelanggan, menghitung total pembayaran,
memantau status pesanan, serta menyimpan riwayat transaksi.

## 📋 Project Scope

### In Scope
- Login pengguna/kasir
- Manajemen menu dan harga
- Pencatatan pesanan
- Perhitungan total pembayaran
- Pengelolaan status pesanan
- Pencatatan pembayaran
- Riwayat transaksi
- Laporan penjualan sederhana

### Out of Scope
- Self-order melalui HP pelanggan
- QR ordering
- Payment gateway / pembayaran online otomatis
- Layanan delivery
- Pengelolaan stok bahan baku
- Penggajian karyawan
- Membership / poin pelanggan
- Promosi dan pemasaran
